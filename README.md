# Gascourt

Répartition des factures d'eau et d'électricité entre les logements d'un corps
de ferme. Une page autonome, sans dépendance ni bibliothèque, qui s'installe sur
un téléphone et fonctionne sans réseau : les relevés se prennent devant les
compteurs, souvent là où il n'y en a pas.

**Ce dépôt ne contient aucune donnée.** La page s'ouvre vierge. Les relevés et
les factures vivent dans un dépôt privé que chaque utilisateur renseigne dans
les réglages, en bas de la page.

Le code source, les tests et le script d'assemblage sont tenus ailleurs, dans un
dépôt privé : son historique porte des données personnelles, et l'on ne rend pas
public un passé.
